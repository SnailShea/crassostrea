# Security policy

## Reporting a vulnerability

Please report security vulnerabilities privately, not in public issues:

    security contact: <ADD THE MAINTAINERS' SECURITY ADDRESS HERE>

Include the affected version (git commit), how to reproduce the problem and
its impact. You will receive an acknowledgement, and updates while a fix is
prepared; the maintainers may ask you for more information.

Vulnerabilities in third-party components (Postfix, Rspamd, ClamAV, MariaDB,
Valkey, nginx and the other distribution packages) should be reported to their
maintainers. Report them here as well if Crassostrea's configuration makes
them exploitable.

## Disclosure policy

When a report arrives, a maintainer:

  * confirms the problem and determines the affected versions,
  * audits the code for similar problems,
  * prepares fixes for all maintained versions and publishes them together
    with an advisory.

## Comments on this policy

Suggestions for improving this process are welcome as pull requests.
