What happens

A message with such an attachment is rejected while the sending server is still connected, so the sender learns that it did not arrive. Inbound mail of a domain with a quarantine is kept there and an administrator can release it. The rejection is in the mail log with the symbol ATTACHMENT_BLOCKED and the file name.

Independently, Rspamd adds to the spam score of risky types it knows (executables, scripts, disk images), and the antivirus and the Office macro check look into the files.

Hash lookups

The hash of every attachment is looked up in databases of known malware, and a hit adds its score (at the reject threshold the message is rejected and quarantined). Only the hash leaves the gateway, never the file. A file nobody has reported yet passes, so this adds to ClamAV rather than replacing it. Results are cached for a day. Sandboxes that open unknown files need a commercial service or appliance and are not included.
