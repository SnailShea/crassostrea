Restoring

Restoring stops the gateway's services, so it is done on the server, as root:

sudo system/backup.sh restore NAME

NAME is a backup in {{ backup_dir }} or the path of a downloaded one. The current configuration and database are saved first. To move the gateway to a new server, install it there with setup.sh, copy a backup over and restore it. A cluster member cannot be restored: restore one node as a single gateway, then rebuild the cluster.
