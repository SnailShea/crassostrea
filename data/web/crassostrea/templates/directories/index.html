Every 15 minutes the addresses of each directory are copied to the recipient lists of the domains that use it (Domains → recipient validation "Only recipients from a directory"). Postfix only reads those lists, so mail keeps flowing while a directory is down. A synchronisation that finds nothing, or would remove more than half of a domain's recipients, is refused and shown here.
