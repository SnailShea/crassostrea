Outbound limits

How many recipients each sender of the relay networks may send to, so a compromised account or device cannot send a flood of spam through the gateway.

Every sender

{{ default_form.csrf_token }} {{ field(default_form.outbound_limit) }} {{ field(default_form.outbound_limit_period) }}

Each envelope sender gets this limit unless it has its own below; bounces count per sending server. 0: no limit. A message is counted once per recipient. Over the limit, mail is deferred (451) and the sending server retries later; a single message with more recipients than the limit is rejected.

An address's limit wins over its domain's, which applies to each sender of the domain on its own. 0: no limit for them. Saving an existing sender changes its limit.
