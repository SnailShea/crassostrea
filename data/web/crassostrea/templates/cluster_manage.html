Maintenance and members

A node in maintenance answers new SMTP connections with a temporary error (421), so senders deliver to the other MX hosts. It hands the Valkey master and the floating address over and keeps delivering its queue. Use it before updating or rebooting a node, one node at a time.

Remove a node only when it is switched off for good (like Proxmox's pvecm delnode): the others drop it from their configuration. Do not start it again with this cluster's data; reinstall it to use it again. A witness host is added on the server: system/cluster.sh members and bundle, then setup.sh --join there.
